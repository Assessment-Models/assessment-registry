# Compatibility declarations

Cross-asset compatibility declarations land here (CR-AM-11 §17): which asset versions interoperate, on which contract versions.

Phase 1 registers assets only; compatibility records are introduced with the first multi-model population (Phase 4+), validated by ecosystem CI (`assessment-ci`).

Declaration syntax will follow the existing schema conventions in dea-metamodel (`compatibility.schema.json` + `governance/compatibility.md`), per CR-AM-11 §17.
